# 青雁批量工具箱 v3.4.0

首次公开发布，以已经完成的 v3.4.0 为基础，采用 GNU AGPL v3 开源。

- 备份管理：独立版本备份、整理旧备份、退出时保留或清理。
- 统一替换：多组规则处理文档内容、文件名和文件夹名，支持预览、取消和撤销。
- 圆润界面、收藏、任务流水线、Office/PDF/图片/文本批处理功能。

下载 `setup.exe` 安装，或完整解压 `windows-x64.zip` 后运行。`source.zip` 提供对应源码，`SHA256SUMS.txt` 用于校验下载内容。

系统要求：Windows 10/11 64 位。Office 保真转换需本机 Office/WPS。程序未进行商业代码签名。内容替换格式与功能边界见仓库使用说明。

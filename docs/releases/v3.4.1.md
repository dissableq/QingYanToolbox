# 青雁批量工具箱 v3.4.1

首个完整自动构建的开源发行版，采用 GNU AGPL v3。

修复了英文 Windows / GitHub Runner 中中文打包日志的编码问题，补充 GitHub API 上传备用方式。保留备份管理、多组规则统一替换、圆润界面、收藏、任务流水线及 Office/PDF/图片/文本批处理功能。

- `QingYanToolbox-3.4.1-setup.exe`：安装包。
- `QingYanToolbox-3.4.1-windows-x64.zip`：完整解压后使用的免安装版。
- `QingYanToolbox-3.4.1-source.zip`：对应提交的源码。
- `SHA256SUMS.txt`：下载文件校验值。

支持 Windows 10/11 64 位。Office 保真转换需本机 Office/WPS。程序未进行商业代码签名。功能边界与复杂文档验证建议见仓库使用说明。

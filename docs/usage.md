# 青雁批量工具箱 v3.4.0

Windows 本地文件批量处理工具，共 22 个页面、169 个操作入口。本版保留 v3.3.0 的圆润界面与原有功能，新增备份管理和内容、名称统一替换。

## 备份管理

原地修改前，在原文件所在目录建立“备份”文件夹。每次处理保存独立版本，避免覆盖上一次备份；同目录旧版 `.qingyanbak` 会一并整理进去，撤销路径同步更新。

右上角“备份管理”可查看、打开和清理备份。“整理已有备份…”可选择目录，递归整理旧版备份。普通批量扫描和统一替换跳过“备份”目录。

本次使用产生或整理了备份时，退出会显示三个选择：

- 保留并退出：保留备份；以后可从“备份管理”查看和清理。
- 清理并退出：只删除本次记录且内容未被外部修改的备份，保留处理结果、以前保留的备份和其他文件。
- 返回软件：取消退出。

清理后不能再用已删除的备份恢复原文件内容。程序不会递归删除整个备份目录。文件名和文件夹名的撤销步骤仍保留。

## 统一替换

从侧栏“统一替换”或首页搜索“统一替换”打开。

1. 选择或拖入目标文件夹。
2. 勾选文件内容、文件名、文件夹名；默认递归包含子文件夹，可另外勾选修改所选文件夹本身。
3. 添加多组查找和替换规则。支持排序、删除、JSON 导入导出。
4. 点击“预览统一任务”，核对变化路径与替换次数；解决重名、无效名称或文件读取错误后再执行。
5. 点击“执行统一任务”。先备份并处理内容，再改文件名，最后从内到外改文件夹名。支持取消与撤销。

规则区分大小写，从上到下连续执行。替换为空表示删除，文件扩展名不参与改名。预览后参数或源文件变化，需要重新预览。

内容支持 Word（docx/docm）、Excel（xlsx/xlsm）、PPT（pptx/pptm）及 TXT、Markdown、CSV、JSON、XML、HTML、日志和常见代码文本。Excel 公式保持不变。PDF、图片、旧版 doc/xls/ppt 等格式只处理名称，预览会明确提示。

复杂文档应对照输出复核。取消保留已完成的操作与撤销记录；台账记录具体成功和失败项目。

## 运行与构建

安装包包含 Python 与依赖。免安装版请完整解压并保留 `_internal` 文件夹。收藏、方案、备份清单与台账保存到 `%APPDATA%/QingYanBatchToolbox`。

```powershell
python -m pip install -r requirements.txt
python main.py
```

```powershell
python -m pip install -r requirements-build.txt
python -m PyInstaller --noconfirm --clean --distpath dist --workpath build/pyi 青雁批量工具箱v3.spec
python make_installer.py --dist dist/青雁批量工具箱v3
```

使用正式中文 spec，以包含必要资源并避免误用其他软件的 DLL。

```powershell
python verify.py
```

验证使用独立样例与用户数据。`test_v34.py` 覆盖备份版本、迁移、清理、多格式统一替换、重名冲突、取消与逐字节撤销。安装包支持 `/S /DIR="目标路径" /NOSHORTCUTS`，程序支持 `--smoke`。

Office 转 PDF、PPT 转图片等功能依赖本机 Office/WPS。PDF 转 PPT 使用页面图片，图片转 Word 不含 OCR；实体打印机和不同办公软件版本需要对应环境验证。
